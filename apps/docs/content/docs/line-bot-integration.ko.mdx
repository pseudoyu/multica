Multica는 직접 만든 LINE 공식 계정의 Messaging API 채널을 사용합니다. 채널 하나가 Multica 에이전트 하나에 대응합니다. 에이전트마다 별도의 LINE 신원이 필요하면 각각 공식 계정을 만드세요.

<Callout type="info">
LINE 연결은 [커뮤니티에서 유지 관리](/community-maintained)합니다. 모든 릴리스에 포함되지만 공식 지원 SLA는 없습니다. 문제는 [GitHub issues](https://github.com/multica-ai/multica/issues)에 알려주세요.
</Callout>

## 시작하기 전에

- 채널 연결은 워크스페이스 owner 또는 admin만 할 수 있습니다.
- LINE은 웹훅으로만 메시지를 전달하므로 API 서버에는 공인 CA 인증서를 쓰는 공개 HTTPS 주소(`MULTICA_PUBLIC_URL`)가 필요합니다. NAT 뒤에 있는 서버에는 터널이나 리버스 프록시가 필요합니다.
- API 서버가 `https://api.line.me`에 접속할 수 있어야 합니다.
- 공식 계정을 만들려면 LINE Business ID가 필요합니다.

## 채널 연결

<Steps>
<Step>

### 공식 계정 만들기 [#1-create-the-official-account]

1. [LINE Official Account Manager](https://manager.line.biz)에서 공식 계정을 만듭니다.
2. **설정 → Messaging API**에서 Messaging API를 활성화하고 provider를 선택하거나 새로 만듭니다.
3. **설정 → 계정 설정**에서 그룹 채팅과 여러 명 채팅 참여를 허용합니다.
4. **설정 → 응답 설정**에서 자동 응답과 인사말 메시지를 끄고 에이전트만 답하게 합니다.

</Step>
<Step>

### 채널 인증 정보 복사 [#2-copy-the-channel-credentials]

1. [LINE Developers Console](https://developers.line.biz/console/)에서 채널을 엽니다.
2. **Basic settings**에서 **Channel ID**와 **Channel secret**을 복사합니다.
3. **Messaging API**에서 **Use webhook**과 **Webhook redelivery**를 켭니다. 웹훅 URL은 비워 두세요. 연결할 때 Multica가 설정합니다.

<Callout type="warning">
Channel secret은 비밀번호처럼 다루세요. 노출되었다면 LINE Developers Console에서 다시 발급한 뒤 Multica에서 채널을 다시 연결하세요.
</Callout>

</Step>
<Step>

### 에이전트에 연결 [#3-connect-it-to-an-agent]

1. Multica에서 **Agents**를 열고 에이전트를 선택한 뒤 **Integrations**를 엽니다.
2. **LINE 연결**을 클릭합니다.
3. Channel ID와 Channel secret을 붙여 넣고 봇 언어를 고른 뒤 **연결**을 클릭합니다.

Multica는 인증 정보로 단기 액세스 토큰을 발급해 검증하고, 봇 정보를 읽고, LINE에 웹훅 URL을 설정한 뒤 테스트를 요청합니다. 시크릿은 암호화해 저장하며 장기 액세스 토큰은 저장하지 않습니다. 다른 에이전트나 워크스페이스에 이미 연결된 채널은 먼저 그쪽에서 연결을 해제해야 합니다.

봇 언어(일본어, 영어, 번체 중국어)는 계정 연결 안내나 상태 알림처럼 봇이 직접 보내는 메시지에 쓰입니다. 에이전트가 답하는 언어는 바뀌지 않습니다.

</Step>
</Steps>

## 처음 사용할 때 [#first-use-and-account-binding]

멤버가 1:1 채팅에서 봇에게 처음 메시지를 보내면 한 번만 쓸 수 있는 Multica 계정 연결 링크를 받습니다. 링크를 열어 같은 Multica 워크스페이스에 로그인한 뒤 LINE으로 돌아와 메시지를 다시 보내세요. 링크는 15분 후 만료되며, 봇에게 다시 메시지를 보내면 새 링크를 받습니다.

그룹에서는 봇이 링크를 공개적으로 보내지 않고, 먼저 1:1로 메시지를 보내 달라고 안내합니다.

현재 워크스페이스 멤버만 봇을 사용할 수 있으며, 멤버십은 메시지마다 다시 확인합니다.

## 봇 사용하기 [#use-the-bot]

### 1:1 채팅

봇을 친구로 추가하고 바로 텍스트를 보냅니다. 멘션은 필요 없습니다.

### 그룹

봇을 그룹 또는 여러 명 채팅에 초대한 뒤 @멘션합니다. 봇을 멘션하지 않은 메시지는 에이전트를 트리거하지 않으며, `@All`은 멘션으로 치지 않습니다. 그룹마다 각자의 Multica 채팅이 이어집니다.

### 명령어

- `/new`는 빈 Multica 채팅을 새로 만들고 이후 LINE 대화의 메시지를 그쪽으로 보냅니다. `/new <메시지>`는 그 메시지를 첫 턴으로 채팅을 만듭니다.
- `/clear`는 현재 Multica 채팅을 유지하면서 다음의 비어 있지 않은 메시지부터 에이전트가 보는 컨텍스트를 새로 시작합니다. `/clear <메시지>`는 그 메시지를 경계 이후의 첫 턴으로 씁니다.
- `/issue <제목>`은 Multica 태스크를 만들며, 다음 줄부터는 선택 사항인 설명이 됩니다. 제목 없는 `/issue`에는 사용법을 답합니다.

### 답장

LINE은 보낸 메시지를 수정할 수 없어 답변은 스트리밍 없이 완성된 뒤 한 번에 도착합니다. 에이전트가 작업하는 동안 1:1 채팅에는 LINE의 로딩 애니메이션이 표시됩니다. 실행이 45초를 넘기면 봇이 먼저 짧은 "작업 중" 메시지를 보내고, 답변이 준비되면 이어서 보냅니다.

답변은 일반 텍스트입니다. 그룹에서는 질문을 인용하고 질문한 사람을 멘션합니다. 긴 답변은 최대 다섯 개의 메시지로 나뉘며, 그 이상은 Multica에 있는 전체 답변 링크로 끝납니다.

현재 LINE은 텍스트 메시지만 처리합니다. 이미지, 파일, 스티커 등 다른 유형에는 1:1 채팅에서 짧은 안내를 답하고 그룹에서는 무시합니다. 어느 경우에도 에이전트로 전달하지 않습니다.

## 비용

메시지에 대한 응답은 무료지만 LINE의 reply token은 약 1분만 유효합니다. 그보다 오래 걸린 답변은 push 메시지로 보내며, LINE은 push를 수신자 수만큼 셉니다. 다섯 명이 있는 그룹에 한 번 push하면 공식 계정의 월간 한도에서 다섯 건이 차감됩니다. 일본의 무료 요금제는 월 200건입니다. Multica는 답변 하나를 요청 한 번으로 보내므로 그룹에서 오래 걸린 답변은 멤버 수만큼 비용이 듭니다. 한도를 다 쓰면 LINE은 다음 달까지 push를 거부하며, 답변은 Multica에 남습니다.

## 연결 관리

**설정 → 메신저 → LINE**에서 연결된 채널과 Multica가 등록한 웹훅 URL을 볼 수 있습니다. owner와 admin은 연결을 해제할 수 있습니다. 해제하면 봇은 답장을 멈추지만 Multica의 대화와 감사 기록은 남습니다.

## 셀프 호스팅 설정 [#self-hosting-setup]

API 서버를 시작하기 전에 고정된 32바이트 암호화 키를 설정합니다.

```dotenv
MULTICA_LINE_SECRET_KEY=<base64로 인코딩한 32바이트 키>
MULTICA_PUBLIC_URL=https://multica.example.com
```

키는 `openssl rand -base64 32`로 만들고 오래 보관하세요. 잃어버리거나 바꾸면 저장된 채널 시크릿을 읽을 수 없어 채널마다 다시 연결해야 합니다.

웹훅 URL은 `MULTICA_PUBLIC_URL`로 만들어지므로 HTTPS여야 합니다. 계정 연결 링크는 `MULTICA_APP_URL`을 쓰고, 없으면 `FRONTEND_ORIGIN`을 씁니다. 서버의 네트워크나 프록시는 `api.line.me`로의 HTTPS 접속을 허용해야 합니다. Go는 표준 `HTTPS_PROXY`와 `NO_PROXY` 환경 변수를 따릅니다.

## 문제 해결 [#troubleshooting]

- **인증 정보가 거부됨**: **Basic settings**에서 Channel ID와 시크릿을 다시 복사하세요. Channel ID는 숫자이며 `@`로 시작하는 basic ID가 아닙니다.
- **웹훅 테스트 실패**: `MULTICA_PUBLIC_URL`이 HTTPS이고 공인 인증서를 쓰며 인터넷에서 접근 가능한지 확인하세요.
- **그룹에서 답이 없음**: 봇의 그룹 참여가 허용되어 있고 그룹에 있는지, 메시지가 봇을 멘션했는지 확인하세요.
- **예상치 못한 자동 응답**: LINE Official Account Manager에서 자동 응답과 인사말 메시지를 끄세요.
- **답변이 더 이상 오지 않음**: 월간 메시지 한도를 다 썼을 수 있습니다. LINE Official Account Manager에서 확인하세요.
- **연결 링크 만료**: 봇에게 1:1로 다시 메시지를 보내고 가장 최근 링크를 쓰세요.
