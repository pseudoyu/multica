Multica は、あなたが作成した LINE 公式アカウントの Messaging API チャネルを使います。1 つのチャネルが 1 つの Multica エージェントに対応します。エージェントごとに別の LINE アカウントが必要な場合は、それぞれ公式アカウントを作成してください。

<Callout type="info">
LINE 連携は[コミュニティメンテナンス](/community-maintained)です。各リリースに含まれますが、公式サポート SLA はありません。問題は [GitHub issues](https://github.com/multica-ai/multica/issues) で報告してください。
</Callout>

## 準備

- チャネルの接続には、ワークスペースの owner または admin 権限が必要です。
- LINE は Webhook でしかメッセージを届けないため、API サーバーには公的な CA の証明書を持つ公開 HTTPS アドレス（`MULTICA_PUBLIC_URL`）が必要です。NAT の内側にあるサーバーにはトンネルかリバースプロキシが必要です。
- API サーバーから `https://api.line.me` に接続できる必要があります。
- 公式アカウントの作成には LINE ビジネス ID が必要です。

## チャネルを接続する

<Steps>
<Step>

### 公式アカウントを作成する [#1-create-the-official-account]

1. [LINE Official Account Manager](https://manager.line.biz) で公式アカウントを作成します。
2. **設定 → Messaging API** を開いて Messaging API を有効にし、プロバイダーを選ぶか作成します。
3. **設定 → アカウント設定** で、グループ・複数人トークへの参加を許可します。
4. **設定 → 応答設定** で、応答メッセージとあいさつメッセージをオフにし、エージェントだけが答えるようにします。

</Step>
<Step>

### チャネルの認証情報をコピーする [#2-copy-the-channel-credentials]

1. [LINE Developers コンソール](https://developers.line.biz/console/)でチャネルを開きます。
2. **チャネル基本設定**で**チャネル ID** と**チャネルシークレット**をコピーします。
3. **Messaging API 設定**で **Webhook の利用**と **Webhook の再送**をオンにします。Webhook URL は空のままで構いません。接続時に Multica が設定します。

<Callout type="warning">
チャネルシークレットはパスワードと同じように扱ってください。漏えいした場合は LINE Developers コンソールで再発行し、Multica でチャネルを接続し直してください。
</Callout>

</Step>
<Step>

### エージェントに接続する [#3-connect-it-to-an-agent]

1. Multica で **Agents** を開いてエージェントを選び、**Integrations** を開きます。
2. **LINE に接続** をクリックします。
3. チャネル ID とチャネルシークレットを貼り付け、ボットの言語を選んで **接続** をクリックします。

Multica は認証情報から短期のアクセストークンを発行して検証し、ボットの情報を読み取り、LINE に Webhook URL を設定してテストを依頼します。シークレットは暗号化して保存し、長期のアクセストークンは保存しません。別のエージェントやワークスペースに接続済みのチャネルは、先にそちらで接続を解除してください。

ボットの言語（日本語、英語、繁体字中国語）は、アカウント連携の案内や状態の通知など、ボット自身が送るメッセージに使われます。エージェントが回答する言語は変わりません。

</Step>
</Steps>

## 初回利用 [#first-use-and-account-binding]

メンバーが初めて 1 対 1 のトークでボットにメッセージを送ると、1 回限りの Multica アカウント連携リンクが届きます。リンクを開いて同じ Multica ワークスペースにサインインし、LINE に戻ってもう一度メッセージを送ってください。リンクは 15 分で失効します。失効したらボットにもう一度メッセージを送ると新しいリンクが届きます。

グループでは、ボットはリンクを公開しません。代わりに、まず 1 対 1 のトークでメッセージを送るよう案内します。

ボットを使えるのは現在のワークスペースメンバーだけです。メンバーかどうかはメッセージごとに確認されます。

## ボットを使う [#use-the-bot]

### 1 対 1 のトーク

ボットを友だちに追加し、そのままテキストを送ります。メンションは不要です。

### グループ

ボットをグループまたは複数人トークに招待し、@ でメンションします。ボットをメンションしていないメッセージではエージェントは動きません。`@All` はメンションに含まれません。グループごとに Multica のチャットが続きます。

### コマンド

- `/new` は空の Multica チャットを作り、以降の LINE のメッセージをそこに送ります。`/new <メッセージ>` はそのメッセージを最初のターンとしてチャットを作ります。
- `/clear` は現在の Multica チャットを残したまま、次の空でないメッセージからエージェントが見るコンテキストを新しくします。`/clear <メッセージ>` はそのメッセージを境界の後の最初のターンにします。
- `/issue <タイトル>` は Multica のタスクを作成します。2 行目以降は任意の説明になります。タイトルのない `/issue` には使い方を返します。

### 返信

LINE は送信済みのメッセージを編集できないため、回答はストリーミングではなく完成してからまとめて届きます。エージェントが作業している間、1 対 1 のトークには LINE の読み込みアニメーションが表示されます。実行が 45 秒を超えると、ボットはまず短い「対応中」のメッセージを送り、回答ができたら届けます。

回答はプレーンテキストです。グループでは、回答は質問を引用し、質問した人をメンションします。長い回答は最大 5 件のメッセージに分かれ、それを超える分は Multica 上の回答全文へのリンクで終わります。

現在 LINE が扱えるのはテキストメッセージだけです。画像、ファイル、スタンプなどには、1 対 1 のトークでは短い案内を返し、グループでは無視します。どちらもエージェントには渡しません。

## 料金

メッセージへの応答は無料ですが、LINE の応答トークンの有効期間は約 1 分です。それより時間のかかる回答はプッシュメッセージで送られ、LINE はプッシュを受信者の人数分としてカウントします。5 人のグループに 1 回プッシュすると、公式アカウントの月間メッセージ数から 5 通分が減ります。日本の無料プランは月 200 通です。Multica は 1 つの回答を 1 回のリクエストで送るため、グループで時間のかかった回答はメンバーの人数分かかります。上限に達すると、LINE は翌月までプッシュを受け付けません。回答は Multica に残ります。

## 接続を管理する

**設定 → メッセージング → LINE** で、接続済みのチャネルと Multica が登録した Webhook URL を確認できます。owner と admin は接続を解除できます。解除するとボットは返信を止めますが、Multica の会話と監査記録は残ります。

## セルフホスト設定 [#self-hosting-setup]

API サーバーを起動する前に、変わらない 32 バイトの暗号化キーを設定します。

```dotenv
MULTICA_LINE_SECRET_KEY=<base64-encoded 32-byte key>
MULTICA_PUBLIC_URL=https://multica.example.com
```

キーは `openssl rand -base64 32` で生成し、長期間保管してください。失ったり変更したりすると保存済みのチャネルシークレットが読めなくなり、各チャネルを接続し直す必要があります。

Webhook URL は `MULTICA_PUBLIC_URL` から作られるため、HTTPS である必要があります。アカウント連携リンクには `MULTICA_APP_URL` を使い、未設定なら `FRONTEND_ORIGIN` を使います。サーバーのネットワークやプロキシは `api.line.me` への HTTPS 接続を許可する必要があります。Go は標準の `HTTPS_PROXY` と `NO_PROXY` 環境変数に従います。

## よくある問題 [#troubleshooting]

- **認証情報が拒否される**: **チャネル基本設定**からチャネル ID とシークレットをもう一度コピーしてください。チャネル ID は数字で、`@` で始まるベーシック ID ではありません。
- **Webhook のテストに失敗する**: `MULTICA_PUBLIC_URL` が HTTPS で、公的に信頼された証明書を持ち、インターネットから到達できるか確認してください。
- **グループで返信がない**: ボットがグループ参加を許可されていてグループにいること、メッセージでボットをメンションしていることを確認してください。
- **意図しない自動応答が出る**: LINE Official Account Manager で応答メッセージとあいさつメッセージをオフにしてください。
- **回答が届かなくなった**: 月間メッセージ数の上限に達している可能性があります。LINE Official Account Manager で確認してください。
- **連携リンクが失効した**: ボットに 1 対 1 でもう一度メッセージを送り、最新のリンクを使ってください。
